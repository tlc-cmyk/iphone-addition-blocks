# 加數積木星星

- Repo：https://github.com/tlc-cmyk/iphone-addition-blocks
- 線上玩：https://tlc-cmyk.github.io/iphone-addition-blocks/

專為 **iPhone** 設計嘅兒童加法練習遊戲。用原創「數字積木」方塊角色學加法，唔係 Numberblocks / BBC 官方內容。

## 點樣喺 iPhone 打開

### 方法一：GitHub Pages（推薦）
1. 用 Safari 打開：https://tlc-cmyk.github.io/iphone-addition-blocks/
2. 點分享按鈕 → **加入主畫面**，就可以好似 App 咁全螢幕玩

### 方法二：本機開啟
1. 下載或 clone 呢個 repo
2. 用電腦開啟 `index.html`，或用任意靜態伺服器
3. 用 iPhone Safari 開同一個 Wi‑Fi 下嘅本機位址；或把檔案傳到手機後用檔案 App / Safari 開啟

```bash
# 本機靜態伺服器例子
cd iphone-addition-blocks
python3 -m http.server 8080
# 然後喺 iPhone Safari 開 http://<電腦IP>:8080
```

## 功能

### 學習區（引導課程）
主畫面「**學習區**」入去，有 **6 課**由淺入深：

1. 認識數字同數粒
2. 10 以內加法
3. 雙同數
4. 跨十加法
5. 缺數同連加
6. 拖數字湊總數

每課：短教學 → 約 9 題引導練習（細賽車道，一題一格）→ 完成後解鎖下一課（進度存本地 `localStorage`）。第 1 課一開始就開放。主獎勵係賽車進度，唔再用星星做主要獎勵。

### 自由練習
- **三關難度**：易／中／難（每關 **30 題**，答對 **20** 就衝線勝出）
- **賽車進度**：答對一題車向前一格；衝線（20 格）即完結勝利
- **倒數計時**：易／中／難一律 **300 秒（5 分）**；時間到顯示行咗幾多格
- **大多數題型**：四選一作答
- **組合數式**：拖動／點選三個數字湊成目標總數（唔係四選一）
- **答對**：賽車向前、簡單慶祝動畫、開心鈴聲
- **答錯**：車唔郁，即刻顯示正確答案，柔和低音提示（唔會嚇親小朋友）
- **音效**：Web Audio 合成（開聲／靜音，預設開聲，記住設定）
- **混合表示**：多數題用阿拉伯數字；少數題用數粒／積木方塊／水果／星星物件
- 題型（按難度比重出現）：
  1. 1–10 簡單加法
  2. 1–20 小一加法
  3. 湊十
  4. 連加三個數
  5. 缺數（□＋5＝12）
  6. 組合數式（拖三個數字湊成目標，空位顯示 □＋□＋□＝N）
- iPhone 直向、安全區、大掣、可加入主畫面（PWA-ish）

## 難度對應（大約）
| 難度 | 主要題型 |
|------|----------|
| 易 | 1–10、湊十、大積木視覺 |
| 中 | 1–20、缺數、輕組合 |
| 難 | 連加三個數、缺數、組合數式 |

## 技術
- 純靜態：`index.html` + `styles.css` + `app.js`
- 無需建置、無需外部圖片／音效檔 CDN
- 音效用 Web Audio API 即時合成（相容 iPhone Safari，首次點擊解鎖）
- 積木角色用 CSS 繪製（原創）
